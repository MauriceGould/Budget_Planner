# BudgetFlow
A production-oriented front-end budget planner built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Monthly dashboard with income, expenses, balance and savings totals
- Add/edit/delete income and expense transactions
- Search, category/type filtering and sorting
- Category spending visualization
- Monthly category budgets with over-budget states
- Savings goals with progress tracking
- localStorage persistence (no bank connection or server)
- Responsive mobile/tablet/desktop layouts
- Keyboard-friendly native dialogs and controls
- 200% zoom-friendly responsive layout and reduced-motion support
- Print stylesheet

## Run
Open `index.html` directly or serve the folder with a local web server such as VS Code Live Server.

## Production note
This is a client-side portfolio/student application. Financial data is stored only in the browser. A real financial product would require authenticated server storage, security/privacy review, backup/sync, and additional compliance work.
